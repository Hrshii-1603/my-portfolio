Harshita Portfolio
==================
Files:
  index.html  - page structure
  style.css   - all styling and animations
  script.js   - projects, skills, tools data + interactions
  images/     - avatar and project images

To finish:
1. Put your CV in this folder named  Harshita-CV.pdf  (the Download CV buttons point to it).
2. Open script.js and add your WhatsApp, LinkedIn and Behance links in the LINKS object at the top.
3. Replace the images in images/ with your original high-quality files (keep the same names).
4. Open index.html in a browser, or upload the whole folder to Netlify, Vercel or GitHub Pages.
